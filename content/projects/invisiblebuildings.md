Locomatrix produces location based games for mobile devices. I was lead developer
of Treasure Hunt, a game which uses visual clues and GPS tracking to lead the
player on a tour of local places. For cross-platform compatibility we used HTML5
and JavaScript so our games would run on a large variety of smartphones.

We collaborated with the University of Brighton to create Invisible Buildings, a
Time Team-like game that uses GPS to allow school children to simulate performing
an archaeological dig on their playing field. It was written in Java and is available
for Android and iOS. I developed a modular system to allow further games to use
the same engine, such as GeoCrash and the ’Yeast of Eden’ Augmented Reality
experience for English Heritage at Lewes Priory and other historical sites.
